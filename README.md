# TaskyAI

TaskyAI — планировщик личных задач с ИИ-ассистентом. Задачу можно создать одной фразой на русском языке, например «каждый второй вторник в 10:00 планерка», а с телефона работать с задачами через бота во ВКонтакте.

Проект делает группа студентов Колледжа ВятГУ в рамках учебной практики (2026–2027).

## Концепция и проблема

Мы делаем TaskyAI для студентов, специалистов и фрилансеров, которые сами планируют учебу, работу и личные дела.

Обычно у такого человека дела разбросаны по разным местам: часть задач в календаре, конспекты и материалы в другом приложении, напоминания в мессенджере. Чтобы завести задачу, нужно заполнить форму из нескольких полей. Регулярные дела приходится копировать вручную, а найти старую запись бывает трудно.

TaskyAI держит задачи, календарь и заметки в одном месте. Ассистент сам разбирает обычную фразу: выделяет дату, время и правило повторения, а если чего-то не хватает, задает уточняющий вопрос. Ничего не меняется, пока пользователь не нажмет «Принять». С телефона задачами можно управлять через VK-бота, без отдельного приложения.

## Основной функционал

В первую версию входят:

- задачи и папки, календарь с видами «День», «Неделя», «Месяц», статистика выполнения;
- ИИ-ассистент в веб-приложении: создает, изменяет и удаляет задачи по текстовой команде, задает уточняющие вопросы и выполняет действие только после подтверждения;
- повторяющиеся задачи: правило повторения задается обычной фразой, один экземпляр серии можно перенести или изменить отдельно от остальных;
- заметки в папках с вложениями до 10 МБ, привязка заметки к задаче, извлечение задач из текста заметки и краткое содержание;
- поиск по задачам, заметкам и папкам с учетом словоформ;
- вход через VK ID, у каждого пользователя свои данные;
- VK-бот: создание задач сообщением, кнопки «Принять» и «Отклонить», утренние и вечерние уведомления;
- двусторонняя синхронизация с Google Calendar.

## Технологии

Next.js 16 и React 19 на клиенте, ASP.NET Core (.NET 10) и EF Core на сервере, PostgreSQL 16, хранилище файлов SeaweedFS. Языковая модель Qwen3-14B-AWQ работает на отдельном GPU-сервере через vLLM. Все компоненты, кроме модели, запускаются в Docker Compose за Nginx.

## Запуск

### Backend

1. Установите инструмент миграций:

   ```bash
   dotnet tool install --global dotnet-ef
   ```

2. В папке `Tasky.API` создайте файл `appsettings.Development.json`: скопируйте в него `appsettings.Development.json.example` и укажите свои данные для БД.

3. Из папки `backend` создайте и примените миграции:

   ```bash
   dotnet ef migrations add InitialCreate --project MainService/Tasky.Infrastructure --startup-project MainService/Tasky.API
   dotnet ef database update --project MainService/Tasky.Infrastructure --startup-project MainService/Tasky.API
   ```

4. Запустите проект:

   ```bash
   dotnet run --project MainService/Tasky.API
   ```

Backend будет доступен по адресу http://localhost:5000.

### Frontend

Нужен установленный [bun](https://bun.sh). Из папки `frontend` выполните:

```bash
bun i
bun run dev
```
